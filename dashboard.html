Comandi

Tutta la filiera in un solo comando.
./catalog.sh all       # raw → clean → build → validate → storefront
./catalog.sh upload    # dry-run del piano di upload
./catalog.sh live      # upload reale (richiede token)

# oppure, con make
make all && make test

# oppure, uno script alla volta
python3 scripts/run_pipeline.py --open
Output: dist/shopify_products.csv, dist/collections.csv, report di validazione, storefront e dashboard.
